#  Experiment 1: Hello World Android Application

> *"The journey of every developer begins with 'Hello World'."* 🚀

---

##  Aim

To develop a simple Android application that displays the message **"Hello World!"** using **Kotlin** in Android Studio.

---

##  Objective

- Learn the basic structure of an Android application.
- Understand the use of Activities and XML layouts.
- Build and run a simple Android application.
- Display a text message on the screen.

---

##  Software Requirements

- Android Studio
- Kotlin
- Android SDK
- Android Emulator / Android Device
- Windows 10/11

---

##  Technology Used

- **Language:** Kotlin
- **IDE:** Android Studio
- **UI Design:** XML
- **Build Tool:** Gradle
- **Platform:** Android SDK

---

##  Concept

Android applications are built using **Activities**, where each Activity represents a single screen of the application. The user interface is created using XML layout files, while the application logic is written in Kotlin.

In this experiment:

- `MainActivity.kt` loads the application.
- `activity_main.xml` contains a `TextView`.
- The application displays the message **"Hello World!"** in the center of the screen.

---

##  Scenario

A beginner learning Android development creates their first application to verify that Android Studio, Kotlin, and the Android Emulator are properly configured. Successfully displaying **Hello World!** confirms that the Android development environment is working correctly.

|------|-------------|
